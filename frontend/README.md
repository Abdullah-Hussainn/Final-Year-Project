# Netlist Builder Frontend

Frontend for the Verilog → Netlist JSON converter.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The frontend will run on http://localhost:3000

## Build

```bash
npm run build
```

## Environment Variables

- `VITE_API_BASE`: Backend API base URL (defaults to same-origin)
